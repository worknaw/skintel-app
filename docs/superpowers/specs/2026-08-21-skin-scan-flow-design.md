# Skin Scan Flow Design

สร้าง UI สแกนผิวสามขั้นในแท็บวิเคราะห์ผิว: เตรียมพร้อม กำลังสแกน และวิเคราะห์ผล ก่อนแสดงหน้าผลเดิม โดยรอบนี้ใช้ภาพและเวลาแบบจำลอง แต่แยกสัญญา `CameraCaptureService` และ `SkinAnalysisGateway` สำหรับระบบจริงในอนาคต

สถานะหลักคือ `prepare`, `scanning`, `analyzing`, `completed` และ `failed` การเปลี่ยนสถานะต้องผ่าน reducer ที่ทดสอบได้ หน้าสแกนมีคำแนะนำตำแหน่งใบหน้าและจำลองการถ่ายอัตโนมัติ หน้าวิเคราะห์แสดงภาพที่ถ่าย overlay animation ข้อความงานย่อย และเปอร์เซ็นต์ เมื่อครบ 100% แสดงผลวิเคราะห์เดิม

UI ใช้สี ฟ้อนต์ ขนาด และ bottom tab bar เดียวกับหน้า Home ไม่มีอิโมจิ ใช้ไอคอนทั้งหมด การยกเลิกและเริ่มใหม่ต้องกลับสถานะเตรียมพร้อมได้
